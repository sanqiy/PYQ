# 朋友圈系统（sanqi）

> 社交内容发布平台 | 作者：sanqiy | [https://xaacn.com](https://xaacn.com)

包含两个版本：PHP 原生版（开箱即用）和 ThinkPHP 8 现代版（功能最全），均支持图文、视频、音乐等内容发布，内置完整的用户系统、后台管理及 API 接口。

## 版本对比

| 特性 | PHP 原生版 (`sanqi/`) | ThinkPHP 8 版 (`sanqi-thinkphp/`) |
|------|----------------------|-----------------------------------|
| PHP 版本 | 7.0+ | 8.0+ |
| 框架 | 无（原生 PHP） | ThinkPHP 8（MVC） |
| 依赖管理 | 无 | Composer |
| 数据库 | MySQL | MySQL / SQLite |
| 安装方式 | Web 安装向导 | Web 安装向导 |

| 云存储 | 又拍云 | S3 兼容存储 |
| 音乐代理 | — | QQ/酷狗/酷我/网易云音乐代理 |
| 抖音解析 | — | 支持 |
| 投票系统 | — | 支持 |
| 标签系统 | — | 支持 |
| 缓存机制 | — | 支持 |
| 配置版本管理 | — | 支持 |
| 升级管理 | — | 版本迁移工具 |
| 操作日志 | — | 支持 |
| 邮件模板 | — | 可编辑 |

### PHP 原生版功能

- 内容发布（图文、视频、音乐、链接）
- 用户注册/登录/个人主页
- 文章评论/点赞
- 后台管理（文章审核、评论审核、用户管理、基础设置、链接管理、邮件设置、图片设置）
- 全站密码保护
- 文章置顶
- 文件上传（头像、封面、图片）
- 邮件发送（phpmailer）
- 又拍云存储集成

### ThinkPHP 8 版新增功能

- **MVC 架构**：80+ 路由端点，中间件、验证器、模型层
- **后台管理**：仪表盘、基础设置、分类管理、权限管理、文章/评论审核、系统通知、用户管理、链接管理、表情管理、邮件设置、云存储设置、安全设置（TOTP 二次验证）、文件管理、操作日志、数据库备份/恢复/迁移、升级管理、配置版本快照与回滚、邮件模板编辑
- **API 接口**：文章（加载更多/保存/Markdown/草稿/删除/隐私/置顶）、认证（登录/2FA/注册/密码重置）、评论、点赞、用户（资料/头像/封面/二维码/IP 定位）、上传（图片/视频/文件）、附件、消息、投票、音乐代理（QQ/酷狗/酷我/网易云）、抖音解析
- **标签系统**、缓存管理、多数据库驱动、CLI 命令行支持

## 快速开始

### PHP 原生版

1. 将 `sanqi/` 部署到 Web 服务器（PHP 7.0+、MySQL）
2. 访问 `http://你的域名/install/` 按向导安装
3. 管理员默认密码：`123456`

### ThinkPHP 8 版

1. 配置 `.env` 数据库连接信息
2. 访问 `http://你的域名/public/` 按向导安装
3. 需 PHP 8.0+ 和 Composer 依赖
